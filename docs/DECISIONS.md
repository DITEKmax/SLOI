# Решения по сравнению с предварительным планом

Все изменения приняты для рабочей, проверяемой реализации, а не подменяют её обещаниями.

| Ранее обсуждалось | В поставке |
|---|---|
| Один venv для всех моделей | Core + 3 изолированных runtime-env, один активный subprocess. Меньше конфликтов, надёжнее выгрузка |
| Native PyTorch GigaAM / большой NeMo | ONNX-экспорты GigaAM и Parakeet, отдельный ONNX CUDA runtime. Реальные веса/качество требуют проверки |
| Parakeet GGUF как предполагаемый спасительный вариант | Не заявляется непроверенный CUDA GGUF путь; FP32 ONNX с короткими фрагментами и явным риском 4 GB |
| Python «самый новый» | 3.13.5 выбран по экосистеме бинарных колёс. Windows installation gate остаётся открытым; 3.14 не установлен автоматически |
| qwen-asr с ограничением старого Transformers | Native Qwen3-ASR в Transformers 5.13.0, no trust_remote_code |
| Vite/Pinia | Vue 3, строгий TypeScript, маленькая offline-сборка и reactive store. Backend остаётся source of truth; Node в production не нужен |
| Native path из drop обычной страницы | Системный picker + отдельный Windows drop bridge; новый браузерный drop требует подтверждения пути. Без скрытого upload |
| UI без authentication вообще | Без аккаунтов, но session/CSRF/Host/Origin необходимы и на localhost |
| RU/EN всегда одинаковый language hint | Возможности runtime отражены явно: Parakeet hint не поддерживает, GigaAM — RU-only |
| Интеллектуальное улучшение текста | Никакой LLM. У Qwen специально не применяется helper, удаляющий повторения; лишь снятие служебных тегов |
| UI без scroll при любом количестве файлов | На проверенных desktop viewport основной экран помещается, длинная очередь прокручивается внутри; на телефоне естественная вертикальная прокрутка |
| Canvas CPU-only | Такое обещание неверно. Небольшая графика с ограничениями, ASR/UI performance test на целевой GPU ещё нужен |
| Шрифты внутри архива | Google Fonts скачиваются во время установки, проверяется кириллица, после этого обслуживаются локально |
| Все стадии Phase 0–9 уже пройдены | Облачные unit/integration/UI gates пройдены. Windows/GPU/полная лекция не пройдены и не обозначены как успешные |
| Metadata о качестве автоматически | WER/CER = null без эталона, нет фиктивных рейтингов точности |
| Название ещё не выбрано | Рабочее имя SLOI: слои сигнала → фрагменты → текст. Проверка товарных знаков не проводилась |

## Следующие реальные gates, а не новый список функций

1. `install.bat` на целевой Windows: четыре runtime, реальные CUDA-сессии, короткая речь, выгрузка.
2. Native picker/drop Windows; отсутствие новой большой медиа-копии.
3. Одна полная RU/RU+EN лекция на четырёх моделях; затем EN запись для универсальных моделей.
4. Сравнение ASR с закрытой вкладкой и активной анимацией, воспроизводимые параметры и источник.

Дальнейшее изменение моделей/precision после этих тестов не должно скрываться под прежними metadata. До их выполнения обозначение релиза остаётся RC.
