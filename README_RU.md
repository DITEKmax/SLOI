# SLOI — локальная расшифровка

**Версия: 1.0.0-rc1.** Windows x64 · Python/FastAPI · Vue/TypeScript · локальный NVIDIA GPU.

SLOI читает существующие аудио- и видеофайлы, последовательно распознаёт их выбранной моделью и выдаёт Markdown: технические метаданные + исходный текст распознавания. Без облачного ASR, LLM, пересказа, редактора и записи микрофона.

## Статус этой поставки

Это установочный комплект с исходниками, собранным интерфейсом, адаптерами четырёх моделей и автоматическими проверками. **Это release candidate, а не подтверждённый на RTX 3050 Ti производственный релиз.**

В облачной Linux-среде проверены 40 автоматических тестов ядра, сборка TypeScript, 15 сочетаний темы и размера окна, 10 UI-взаимодействий. Проверки ядра используют настоящий FFmpeg/SQLite/HTTP/процессы, но тестовые ответы ASR. В облаке нет NVIDIA GPU и доступа к вашему компьютеру. Реальные модели, CUDA на Windows, системное окно выбора файлов, Windows drop и установка с чистой Windows здесь не запускались. Полная лекция для качественного benchmark не предоставлена.

Установка выполняет настоящие GPU smoke-тесты уже на целевой машине. Она не заменяет ошибку модели фиктивной расшифровкой и не переключает ASR незаметно на CPU. Ограничения установки и проверки описаны в `DEPLOYMENT_RU.md` и `docs/`.

В публичный репозиторий входят исходники и собранный интерфейс. Модели, окружения, результаты, журналы и отчёты установки остаются локальными; пользовательский `config/app.yaml` также не публикуется. Если этого файла нет, приложение использует `config/defaults.yaml`.

## Быстрый старт

1. Распаковать весь каталог `SLOI`, например в `D:\SLOI`. Не запускать из ZIP.
2. Установить актуальный NVIDIA-драйвер, если он ещё не установлен. Интернет нужен при первой установке.
3. Запустить `install.bat`. Python, окружения, FFmpeg, модели и шрифты будут подготовлены внутри проекта.
4. Посмотреть итог установки. Код 0 — короткие GPU-тесты прошли; код 2 — среда установлена, но GPU-проверка неполная/с ошибками; код 1 — установка не завершилась.
5. Запустить `start.bat`. Откроется `http://127.0.0.1:8765`. Консоль backend оставить открытой.
6. Добавить файлы, выбрать модель/основной язык, запустить очередь. Готовые MD скачиваются штатным механизмом браузера.

Подробно: **`DEPLOYMENT_RU.md`**.

## Что реализовано

| Область | Возможности |
|---|---|
| Медиа | FFprobe, выбор первой подходящей аудиодорожки, FFmpeg pipe, ограниченные буферы; исходники не меняются |
| Распознавание | GigaAM v3 E2E RNNT, Qwen3-ASR 0.6B, Whisper RU Stage AW, Parakeet TDT v3; отдельные runtime-окружения и один активный worker |
| Подготовка | Silero VAD на CPU, консервативные границы, перекрытие сегментов, отдельные настройки для каждой модели |
| Очередь | SQLite, модель/язык для каждого задания, перестановка ожидающих, удаление, пауза после текущего, отмена, продолжение после ошибки |
| Восстановление | Закрытие вкладки не влияет на backend; после перезапуска готовое сохраняется, прерванное начинается заново по команде |
| Результат | UTF-8 MD с YAML, уникальное имя, атомарная запись, скачать/ZIP/копировать текст/показать в Проводнике |
| Мониторинг | Настоящие NVML/psutil, GPU/VRAM/CPU/RAM/температура/мощность, история, скорость, ETA; недоступные показатели — прочерк |
| Дизайн | Carbon, Paper, Signal: отдельные типографика, геометрия, цвет и визуализация; акцент, reduced motion, адаптивная сетка |
| Развёртывание | Локальный Python 3.13.5, раздельные зависимости, закреплённые ревизии моделей, диагностика, обновление с резервной копией |

## Добавление без копирования: существенная особенность

Обычный браузер не раскрывает абсолютный Windows-путь перетаскиваемого файла. Поэтому реализованы три честных маршрута:

- **Добавить файлы** — системный Windows picker, backend получает пути без загрузки содержимого в браузер.
- **Windows drop** — небольшое нативное окно-приёмник, куда перетаскиваются файлы из Проводника; приложение получает пути без копии.
- **Перетаскивание на SPA** — уже зарегистрированные файлы узнаются по метаданным. Для нового файла потребуется подтверждение оригинала системным picker. Скрытого HTTP-upload всего видео нет.

Именно бесшовный drag-and-drop нового файла прямо в обычную веб-страницу с получением абсолютного пути **не реализован**: браузер не предоставляет такой доступ. Не установлены расширения, глобальные перехватчики или Electron.

## Модели и язык

| Модель | Фактический runtime | Особенности |
|---|---|---|
| GigaAM v3 E2E RNNT | ONNX-ASR + ONNX Runtime CUDA | Русский; EN-задания отклоняются |
| Qwen3-ASR 0.6B | Transformers 5.13 + PyTorch CUDA | AUTO/RU/EN; подсказка языка влияет на декодирование |
| Whisper RU Stage AW | faster-whisper + CTranslate2, INT8/FP16 | Русский fine-tune; английский может быть хуже исходного Turbo |
| Parakeet TDT 0.6B v3 | ONNX-ASR + ONNX Runtime CUDA | Определяет язык самостоятельно; RU/EN сохраняется как пожелание, а не несуществующий аргумент модели |

Смешанная речь не запрещается приложением, но качество RU↔EN не гарантируется одной настройкой. Совместимость с 4 GB VRAM и реальная скорость всех четырёх моделей пока не измерены на целевой машине. Особенно важно проверить Parakeet FP32; уменьшение длины фрагмента не уменьшает сами веса.

## Полезные файлы

- `config/app.yaml` — локальные технические переопределения; интерфейс их не раскрывает и файл не входит в репозиторий.
- `config/defaults.yaml` — базовые параметры.
- `config/models.manifest.json` — репозитории и неизменяемые ревизии моделей.
- `docs/ARCHITECTURE.md` — фактическое устройство, ограничения и определения метрик.
- `docs/DECISIONS.md` — отличия от предварительного обсуждения.
- `docs/SOURCES.md` — первичные источники.

Веса и исполняемые зависимости не включены в ZIP. Шрифты также загружаются установщиком, а не поставляются в архиве. Обычный запуск после успешной установки не требует Node.js и не скачивает файлы.
